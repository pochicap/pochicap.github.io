Windows 用 画面キャプチャツール

伝えたい画面を、
ショートカット1回で。

ポチキャプは、いま見ているウィンドウをすぐにキャプチャし、四角枠・番号・モザイクで「どこを見てほしいか」を伝えられる Windows アプリです。編集画面を閉じるだけでクリップボードへコピーされ、AI チャットやメールにそのまま貼り付けられます。

無料 ｜ Windows 11（x64）

  • アカウント登録なし
  • 広告なし
  • 画像を提供者へ送信しない
FEATURES

「ここを見て」が伝わる、3つの機能

撮る・示す・隠すが、ひとつの流れで完結します。

01

すぐにキャプチャ

Alt+Shift+S で、前面にあるウィンドウをキャプチャ。すぐに編集画面が開きます。5 秒後に撮る Alt+Shift+D もあり、ショートカットは変更できます。

02

囲んで、番号で示す

四角枠（3 色）と番号付きの手順マーカーで、見てほしい場所と順番をはっきり伝えられます。

03

見せたくない所は隠す

モザイクで、番号や個人の情報など見せたくない部分を隠してから共有できます。

そのほかの機能

  • 切り抜き
  • 元に戻す・やり直し
  • 自動保存（選んだフォルダーに PNG）
  • タスクトレイに常駐
  • ショートカットの変更
HOW IT WORKS

使い方は 3 ステップ

  1. 1

    撮る

    見せたいウィンドウを前面に出して Alt+Shift+S。

  2. 2

    伝える

    必要に応じて、四角枠・番号・モザイクを加えます。

  3. 3

    貼る

    編集画面を閉じるとクリップボードへ。AI チャットやメールの入力欄で Ctrl+V。

PRIVACY

安心してお使いいただくために

アカウント登録なし

インストールしてすぐに使えます。ログインや会員登録は必要ありません。

広告なし

アプリの中に広告は表示されません。作業に集中できます。

画像を送信しない

キャプチャした画像や利用状況を、提供者へ送信しません。

編集画面の表示に使う Microsoft Edge WebView2 Runtime が、Microsoft のサービスと通信する場合があります。詳しくはプライバシーポリシーをご覧ください。

STORY

小さな手間を、なくすために。

AI に画面を見せて質問するとき、「どこを見てほしいか」を伝えるたびに画像編集ソフトを開くのは、小さいけれど繰り返す手間でした。ポチキャプは、その手間をなくすために生まれたアプリです。
