ポチキャプ プライバシーポリシー

制定日：2026年9月28日
運営・お問い合わせ：ポチキャプ サポート（以下「提供者」）

ポチキャプ（以下「本アプリ」）は、Windows の画面上のウィンドウをキャプチャし、クリップボードへコピーするためのアプリです。本ポリシーは、本アプリが扱う情報とその取り扱いを説明します。

1. 提供者が収集する情報

提供者は、本アプリを通じて利用者の情報を収集しません。 本アプリには、利用状況の送信（アクセス解析・テレメトリ）、広告、アカウント登録、ログインの機能はありません。キャプチャした画像や利用者のコンテンツを提供者へ送信する機能もありません（編集画面の部品による通信は §3）。

2. 本アプリが利用者の PC の中で扱う情報

本アプリは次の情報を、利用者の PC の中だけで扱います。提供者に送信されることはありません。

情報内容保存される場所
キャプチャした画像ショートカットキーを押したときに前面にあったウィンドウの画像。編集画面で編集し、閉じるとクリップボードへコピーされますメモリの中とクリップボード。自動保存が ON のときだけ、利用者が選んだ保存先フォルダーに PNG ファイルとして保存
設定自動保存の ON / OFF、保存先フォルダーの場所、ショートカットキー本アプリ専用のデータ領域（Windows がアプリごとに用意する場所）
編集画面の表示部品のデータ編集画面の表示に使う Microsoft Edge WebView2 が作成するデータ本アプリ専用のデータ領域

キャプチャした画像には、画面に表示されていた内容（文章や個人情報を含む場合があります）がそのまま含まれます。貼り付け先（AI サービスなど）へ送る前に、必要に応じて編集画面のモザイク等で隠してください。貼り付け先での取り扱いは、それぞれのサービスの規約・ポリシーに従います。

3. Microsoft Edge WebView2 による通信

本アプリは、編集画面の表示に Microsoft Edge WebView2 Runtime（Microsoft が提供する Runtime）を使用しています。Microsoft Edge WebView2 Runtime が Microsoft のサービスと通信する場合があります。 本アプリの提供者は、この Runtime の通信を利用して利用者の情報を収集する機能を実装していません。WebView2 Runtime の通信の取り扱いは、Microsoft のプライバシーに関する声明に従います。

4. アンインストールしたとき

本アプリをアンインストールすると、設定と編集画面の表示部品のデータ（本アプリ専用のデータ領域）は削除されます。 自動保存で利用者が選んだ保存先フォルダーに保存された画像は削除されず、残ります。

5. Microsoft Store について

本アプリは Microsoft Store から配布されます。入手・更新・評価などで Microsoft が扱う情報は、Microsoft のプライバシーに関する声明に従います。提供者は、Microsoft から、個人を特定しない集計の情報（入手数など）を受け取る場合があります。

6. 第三者への提供

提供者は、本アプリを通じて利用者の情報を収集しないため、第三者へ提供することはありません。

7. 改定

本ポリシーを改定する場合は、このページで公開します。
